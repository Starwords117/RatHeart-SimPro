# RatHeart-SimPro · 大鼠心血管实验台（v0.2.0）

用 TypeScript 重构 RatCVS 3.3.7 的大鼠心血管系统仿真，并建立中文 Web 操作界面。
计算在 Web Worker 中推进，界面绘制 ABP / LVP / VBP / HF / HR 五通道图纸记录仪曲线。
全部实验计算在浏览器本地完成。

原始心血管仿真模型作者：John Dempster, University of Strathclyde。
原项目：<https://github.com/johndempster/RatCVS>（RatCVS-3.3.5 目录内源码为 V3.3.7 (30.07.20)）。

## 两种使用模式

### Online · 教师授课广播（学生零安装）

授课广播在网页版与桌面安装版中均可使用：桌面版启动时自动内嵌局域网服务
（监听 0.0.0.0,默认端口 5189,被占用自动 +1;Windows 首次运行请允许防火墙访问），
点「开始授课广播」即可,无需 `npm start`。

1. 教师机运行 `npm start -- --lan`（网页版;开放局域网并打印访问地址）
2. 教师打开该地址做实验，点击「开始授课广播」
3. 学生手机 / 平板 / 鸿蒙设备连同一 Wi-Fi，浏览器打开 `http://<教师机IP>:5189/follow.html`
   —— 实时看到老师的动物模型、五通道曲线与每一步操作（只读，直播中轮询与推送均为亚秒级，跟随延迟约 ≤0.3 s）
   开启广播后，界面会自动显示教学机的局域网地址（含跟随页链接），无需手查 IP。

### Local · 学生本地安装

三平台安装包已在 Linux 构建机打包完成（产物在 `release/`，流程见
[docs/三平台打包说明.md](docs/三平台打包说明.md)）：

| 平台 | 安装包 | 产物 |
| --- | --- | --- |
| Windows | portable 免安装 / NSIS 中文安装版 | `RatHeart-SimPro-*-Portable.exe` / `RatHeart-SimPro-*-Setup.exe` |
| Linux | AppImage / deb | `RatHeart-SimPro-*-AppImage` / `ratheart-simpro_*_amd64.deb` |
| macOS | zip（Intel + Apple Silicon，解压即用；dmg 需在 macOS 上构建） | `RatHeart-SimPro-*-mac.zip` |

安装后双击即用（无需 Node.js）;桌面版内置局域网广播服务,可直接授课（Windows 首次运行允许防火墙访问）。实验文件：`保存完整实验`（JSON，含全部状态与
波形）、`导出波形数据`（CSV）、`导出当前曲线`（PNG）、`导出原版记录文件`
（`.rat`，与 RatCVS 原版软件互通）均写入系统下载目录；
`导入实验` 可读取 JSON 继续计算或 `.rat` 回看原版波形。

## 本地开发运行

```bash
npm start          # http://127.0.0.1:5173 （加 --lan 开放局域网，--port 改端口）
npm run build      # TypeScript → dist/（Node 22.6+ 类型剥离，低版本回退全局 esbuild）
npm test           # 49 项内核核验 + 8 项 Worker 消息链核验
```

不要直接双击 `dist/index.html`：模块与 Worker 需经本地 HTTP 服务加载。

## 教学内容

- **动物模型**：去脑大鼠（标准制备，无神经反射）/ 正常大鼠（压力感受器反馈 + 基础交感张力），开始记录后锁定。
- **药物**：原版 9 种激动药 + 14 种拮抗/抑制药 + 11 种未知药（Drug A–K 盲检）。
  剂量序列 1/2/5×10ⁿ（μg/kg 或 mg/kg），与原版 `SetDoseList` 完全一致。
- **神经刺激**：交感（血管/心脏/肾上腺支）、肾神经、迷走神经 5 条通路。
- **五通道记录**：ABP 动脉血压、LVP 左心室内压、VBP 中心静脉压、HF 心收缩力、HR 心率；
  药物标注、绿色测量光标、回看滑块、显示窗口 ×2/÷2。
- **特殊状态**：动脉压 < 20 mmHg 持续 → 大鼠死亡；地高辛 ≥ ~10 mg/kg → 心室颤动、射血停止。
- **教学增强**：**对比叠加**（把当前窗口存为半透明对比曲线,便于给药前后对照）、
  **量效曲线工具**（按给药事件自动计算前后反应,表格 + 对数散点图 + CSV 导出）、
  **测量工作表**（光标取数逐行填表,CSV 导出）、死亡后曲线拉平开关（原理与设置,默认保持原版室颤行为）。
- **文件**：完整实验 JSON（可继续计算）、五通道 CSV、曲线 PNG、
  **原版 `.rat` 记录文件导入/导出**（与 RatCVS 原版软件互通）。
- 浏览器本机自动保存（localStorage，最近约 10 分钟波形 + 全部状态）。

## 数学基线

三室集总参数模型（心脏 / 动脉 / 静脉 + 两个单向阀），积分步长 0.125 ms，
每显示点 100 步并输出 2 个子样本；受体激活与血药动力学每 5 ms 更新。

```text
竞争性受体占领：激活量 = Σ(效能ᵢ·xᵢ) / (1 + Σxᵢ)，xᵢ = 剂量ᵢ / (效力ᵢ × shift)
血药动力学：   dDose/dt = k_on·(Injected − Dose) − k_off·Dose（每 5 ms 更新）
心收缩弹性：   exp(−x²)·Force 脉冲；PDE 抑制使 β 效力 shift = 1 − PDE×0.5
压力感受器：   迷走张力 = 5/(1+e^(−(MAP−130)/8))（仅正常大鼠）
```

目录中的效力参数为原版剂量尺度常数（mg/kg），不能直接视为实测结合常数。

## 相对原版的明确改动

1. 波形以浮点物理量保存与绘制，仅在 `.rat` 导出时按原版量化为 int16。
2. 使用可记录种子的随机数发生器（mulberry32）；分布形式与原版一致
   （效力 ±50%、注射剂量 ±10%、心率记录 ±5%），但随机序列与 Delphi RTL 不同。
   原版每次启动序列固定；本版每个实验可用不同种子，可在「原理与设置」中关闭噪声。
3. 时间轴为生理时间（子样本间隔 6.25 ms），与心率读数一致。
   原版按 1/4 实时速度走纸且名义标定与实际不一致；本版默认回放速度 0.25×
   （还原原版视觉节奏），时间轴本身不再失真，速度可调 1×/2×/5×。
4. 图表标注短名：酚妥拉明由原版与去氧肾上腺素重名的 `Phe` 改为 `Phen`。
5. 中文界面；事件记录含时间戳并随快照保存。
6. 自动保存截取最近约 96000 子样本（≈10 分钟）以控制 localStorage 体积。

## 保留的原版行为（含缺陷复刻）

- **刺激「交感神经（心脏支）」实际注入肾上腺素**：原版 RATMAIN.PAS 中
  `iSympHeart` 声明后从未赋值（恒为 0），`Drugs[0]` 即肾上腺素。本版按原版行为复刻并在代码注释与说明中标注。
- 迷走神经递质 `RemovalRate := FastOn*4.0`（疑似应为 FastOff）按原版保留。
- `NicChR`（神经节 N 受体）计算后不进入任何效应方程（原版已注释掉），保留计算以维持剂量序列一致。
- 标注单位判定在注射时用「剂量 < 1.0 → μg/kg」，与剂量下拉的单位规则（MaxDose ≤ 1）不完全一致，
  0.5 mg/kg 腺苷会标注为 `Ade 500 ug/kg`——按原版保留。
- Captopril 不再激动缓激肽受体（原版 V3.3.0 起移除），BradR 通路保留但恒为 0。

## 验证

- 49 项内核核验：确定性黄金参考值（seed=42, noise=false）、
  与原版 `.rat` 记录逐项对照的基线与药物反应（基线 ABP 93.1/收缩 121/舒张 69、HR 351、
  VBP 7.6，对照原版记录 92.3[60–121]/351/7.6）、竞争拮抗与阻断、颤动与死亡、
  快照续算逐点一致、真实 `.rat` 导入与导出往返、截断文件拒绝。
- 8 项 Worker 消息链核验（Node worker_threads 桥接浏览器 Worker 文件）。
- 浏览器实测：记录/暂停、注射、阿托品阻断 Ach、神经刺激、未知药页签、
  原理与设置、自动保存恢复、授课广播与跟随页、`.rat` 导入导出。
