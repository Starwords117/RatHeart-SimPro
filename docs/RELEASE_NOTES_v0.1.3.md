## RatHeart-SimPro v0.1.3

大鼠心血管系统药理实验模拟（RatCVS 3.3.7 模型的 TypeScript 重构；原模型 © John Dempster, University of Strathclyde）。

### 下载

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `RatHeart-SimPro-0.1.3-x64-Setup.exe` | 安装版（中文向导） |
| Windows | `RatHeart-SimPro-0.1.3-x64-Portable.exe` | 免安装版 |
| Linux | `RatHeart-SimPro-0.1.3-x86_64-AppImage` | 通用免安装 |
| Linux | `ratheart-simpro_0.1.3_amd64.deb` | Debian / Ubuntu |

| macOS（Apple Silicon） | `RatHeart-SimPro-0.1.3-arm64-mac.zip` | 解压即用 |

安装包未签名：Windows 首次运行 SmartScreen 提示「仍要运行」（并允许防火墙访问，授课广播需要）；macOS 首次打开需右键 → 打开。完整性校验见 `SHA256SUMS.txt`。

### 本版新内容（相对 v0.1.2）

- **桌面版内置授课广播**：安装版/免安装版启动即自动开启局域网服务
  （默认端口 5189，被占用自动顺延），点「开始授课广播」即可授课——学生端
  依然零安装，浏览器打开提示的地址即可实时跟随；不再需要 `npm start -- --lan`。
- **跟随延迟 ≤0.5s**：教师端推送 300ms 一批 + 学生端自适应轮询
  （跟随中 0.2s、等待时 1.5s）+ 渲染 150ms。
- **授课广播可靠性**：修复停止广播按钮无反应；教师停止后学生跟随页回到等待空态；
  学生误开主页时顶部出现「进入跟随页」引导横幅。
- **局域网地址自动提示**：开启广播后显示主地址（路由自动探测），
  点击 ⓘ 可展开其他网段备用地址。
- **大屏布局**（≥1920 视口）：曲线显示区 1460×640（约 +135%），
  「导入实验/导出」移入走纸控制行；笔记本/手机布局不变。
- **五通道图表**：通道带间 18px 间隔消除左轴刻度重叠，0 轴基线加粗。
- **修复：「原理与设置」对话框无法打开**（自第一版起即存在的空指针）。

### 主要内容

- RatCVS 3.3.7 三室心血管模型完整移植（去脑 / 正常大鼠双模型；49 项内核核验 + 8 项 Worker 核验，基线与原版 `.rat` 记录逐项吻合）
- 42 条药物（含 11 种未知药盲检）、5 条自主神经刺激通路
- 五通道图纸记录仪（ABP / LVP / VBP / HF / HR）、药物标注、测量光标、回看
- 原版 `.rat` 记录文件导入 / 导出互通
- PWA 离线可用（网页模式）

### 已知限制

- 默认 0.25× 回放速度为原版走纸节奏（时间轴为生理时间），可切换 1× / 2× / 5×
- 无代码签名（教学内网分发无碍）
- 自动保存保存在浏览器 localStorage，最近约 10 分钟波形
