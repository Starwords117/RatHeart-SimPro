大鼠心血管系统药理实验模拟（RatCVS 3.3.7 模型的 TypeScript 重构；原模型 © John Dempster, University of Strathclyde）。

### 本版新内容（相对 v0.1.3）

- **自动保存体积 7MB → 1.3MB**：波形改 int16 紧凑编码（与 .rat 同精度），
  Firefox/Safari（5MB 配额）不再溢出；手动导出的 JSON 保持全精度不变。
- **修复：长实验广播白屏**：教师端恢复长实验后开播，推送载荷携带整条
  trace（可达十几 MB）超过服务器上限被销毁——现在推送窗口化
  （最近 18000 帧），学生端在任意录制时长下都能正常跟随。
- **修复：教师页直接关闭/刷新未点停止时**，广播会话残留导致学生端
  永远显示「教师端连接已中断」——服务器 60s 后自动清空会话。
- **跟随页增强**：回看进度条（拖动查看整条曲线）、仿真时间本地走表
  （秒数连续平滑，不再随推送批次跳变；教师暂停/中断时冻结）、
  实验记录列表内边距。
- **跟随延迟 ≤0.3s**：教师推送 150ms + 学生轮询 50ms（压测 50 学生并发
  p50 延迟 1ms、零错误）+ 渲染 100ms。
- **实验记录列表**弹性填满卡片高度，消除下方留白。

### 主要内容

- RatCVS 3.3.7 三室心血管模型完整移植（去脑 / 正常大鼠双模型；49 项内核核验 + 8 项 Worker 核验，基线与原版 `.rat` 记录逐项吻合）
- 42 条药物（含 11 种未知药盲检）、5 条自主神经刺激通路
- 五通道图纸记录仪（ABP / LVP / VBP / HF / HR）、药物标注、测量光标、回看
- 原版 `.rat` 记录文件导入 / 导出互通
- 授课广播（教师端一键广播、学生浏览器跟随页）、PWA 离线可用（网页模式）

### 已知限制

- 默认 0.25× 回放速度为原版走纸节奏（时间轴为生理时间），可切换 1× / 2× / 5×
- 无代码签名（教学内网分发无碍）
- 大鼠死亡后心收缩力/心室压仍显示室颤波形（忠实复刻原版模型行为）
