### 本版新内容（相对 v0.1.4）

**授课广播体系升级**

- **多教师房间隔离**：每位教师一个房间号，跟随链接携带 `?room=`——两位老师同时开课不再互相干扰
- **教师令牌防伪造**：推送/停止广播需携带教师令牌，学生只读无法伪造广播画面
- **跟随端 SSE 长连接**：每学生 1 条常驻连接替代高频轮询，大幅降低课堂 Wi-Fi 空口压力；断线自动回退轮询
- **跟随页回放缓冲**：曲线与仿真时间以教师生成速率匀速走纸（本地插值），平滑性与网络批次解耦；教师暂停自然冻结，快进后自动追赶
- **页面隐藏自动降级**：学生锁屏/切走时自动暂停跟随，回前台恢复
- **停止竞态修复**：教师停止广播后在途推送被忽略，学生端可靠回到等待空态
- **教师页刷新后重新开课**：房间号持久化，学生原链接保持有效

**教学功能**

- **对比叠加**：「＋对比」把当前显示窗口存为半透明对比曲线，多组叠加便于给药前后对照
- **量效曲线工具**：按给药事件自动计算给药前后 ABP/HR 反应，表格 + 对数剂量散点图 + CSV 导出
- **测量工作表**：点击曲线放置光标，取数逐行填表，CSV 导出
- **死亡后曲线拉平开关**（原理与设置；默认保持原版室颤行为）

**工程质量**

- TypeScript 类型检查接入流水线（`npm run check`），类型错误清零
- 广播链路端到端测试（真实 Worker + 服务器，9 项核验：房间隔离/令牌鉴权/停止竞态）
- Playwright headless UI 端到端测试 3 项
- GitHub Actions：push/PR 自动检查测试，push tag 自动三平台构建发布

### 主要内容

- RatCVS 3.3.7 三室心血管模型完整移植（去脑 / 正常大鼠双模型；52 项内核核验 + 8 项 Worker 核验 + 9 项广播端到端核验，基线与原版 `.rat` 记录逐项吻合）
- 42 条药物（含 11 种未知药盲检）、5 条自主神经刺激通路
- 五通道图纸记录仪（ABP / LVP / VBP / HF / HR）、药物标注、测量光标、回看
- 原版 `.rat` 记录文件导入 / 导出互通
- 自动保存紧凑编码（约 1.3MB），PWA 离线可用（网页模式）

### 已知限制

- 默认 0.25× 回放速度为原版走纸节奏（时间轴为生理时间），可切换 1× / 2× / 5×
- 无代码签名（教学内网分发无碍）
- 大鼠死亡后心收缩力/心室压仍显示室颤波形（忠实复刻原版模型行为；可在「原理与设置」开启死亡后曲线拉平）
