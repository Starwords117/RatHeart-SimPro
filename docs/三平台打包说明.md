# 三平台安装包打包说明（Windows / Linux / macOS）

在 **Fedora Linux 构建机**（无 sudo、无代码签名）上实测通过的完整流程。
产物输出到 `release/`。

## 0. 前置条件

```bash
npm run build        # 生成 dist/
cp -a /home/starwords/桌面/模拟软件重写/web/node_modules .   # 或 npm install
# build/icon.png（512×512）与 build/icon.icns 已随项目提供
```

## 1. 环境变量（必须）

electron-builder 需要从 GitHub 下载各平台 Electron 与构建工具，直连经常超时。
统一使用 npmmirror 镜像：

```bash
export ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
export ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"
export CSC_IDENTITY_AUTO_DISCOVERY=false    # 跳过 macOS 签名探测
```

## 2. 三条命令

```bash
npx electron-builder --win --x64 --publish never
# → RatHeart-SimPro-0.1.0-x64-Portable.exe（免安装）
# → RatHeart-SimPro-0.1.0-x64-Setup.exe（NSIS 中文安装向导）

npx electron-builder --linux --x64 --publish never
# → RatHeart-SimPro-0.1.0-x86_64-AppImage（通用免安装）
# → ratheart-simpro_0.1.0_amd64.deb（Debian/Ubuntu）

npx electron-builder --mac zip --x64 --arm64 --publish never
# → RatHeart-SimPro-0.1.0-mac.zip（Intel）
# → RatHeart-SimPro-0.1.0-arm64-mac.zip（Apple Silicon）
```

## 3. 本机已知的两个坑及解决办法

### 3.1 deb 构建报 `fpm process failed 127`

内置 ruby 需要 `libcrypt.so.1`（GLIBC_2.2.5 版本符号），Fedora 44 只有
`libcrypt.so.2` 且 `sudo` 不可用。解决：从 Fedora 源手动提取 compat 库并加入
`LD_LIBRARY_PATH`（~/.local/ratcvs-build-libs/ 已建好）：

```bash
mkdir -p ~/.local/ratcvs-build-libs /tmp/libxcrypt && cd /tmp/libxcrypt
curl -sO https://dl.fedoraproject.org/pub/fedora/linux/releases/44/Everything/x86_64/os/Packages/l/libxcrypt-compat-4.5.2-3.fc44.x86_64.rpm
rpm2cpio libxcrypt-compat-4.5.2-3.fc44.x86_64.rpm | cpio -idm
cp -a usr/lib64/libcrypt.so.1* ~/.local/ratcvs-build-libs/
export LD_LIBRARY_PATH=$HOME/.local/ratcvs-build-libs
```

（若有 sudo：`sudo dnf install -y libxcrypt-compat` 即可，无需 LD_LIBRARY_PATH。）

### 3.2 macOS dmg 在 Linux 上不可构建

`dmg-builder` 依赖 macOS 独有的 `hdiutil`（磁盘映像）与 `sips`（图像处理），
Linux 无法提供，故 mac 目标配置为 **zip**（内含 `RatHeart-SimPro.app`，解压即用）。
如需 dmg：在任意 macOS 机器上 `npx electron-builder --mac dmg --publish never`。
